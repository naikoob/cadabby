# Epistemic Trust Tiers

Epistemic trust tiers classify knowledge into strict auditability classes:
- human-reviewed: Directly checked by a human practitioner.
- machine-confirmed: Verified by an autonomous agent against sources.
- stale-verified: Previously verified content that has since drifted.
- unverified: Newly drafted content without attestation.
